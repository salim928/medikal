💾 SQL Debugging Queries

Run these in Supabase SQL Editor
1 Check if user exists: 
SELECT id, email, email_confirmed_at, confirmed_at, created_at, 
       raw_user_meta_data
FROM auth.users 
WHERE email = 'YOUR_EMAIL_HERE';
2 Check profile exists: 
SELECT * FROM public.profiles 
WHERE email = 'YOUR_EMAIL_HERE';
3 Manually confirm email (if needed): 
UPDATE auth.users 
SET email_confirmed_at = NOW(),
    confirmed_at = NOW()
WHERE email = 'YOUR_EMAIL_HERE';
4 Reset password (if needed): 
-- First, delete the user in Supabase Dashboard
-- Then signup again with the same email

⚠️ Common Login Issues

1 Invalid login credentials
  • Wrong email or password
  • Email not confirmed (check Supabase settings)
  • Account deleted and recreated (old sessions interfering)
  • User doesn't exist in auth.users table
2 Email confirmation required
  • Go to Supabase Dashboard → Auth → Providers → Email
  • Uncheck "Enable email confirmations"
  • Or manually confirm email with SQL query above
3 Session not persisting
  • Clear browser cache and cookies
  • Try in incognito/private mode
  • Check localStorage is enabled
